# ارزیابی agent «گزارش حجم عملیات»

> وضعیت: **هنوز با مدل واقعی اجرا نشده.** ابزار آماده است؛ نتیجه‌ی واقعی باید بعد از ساخت golden set انسانی (≈۱۵۰ ردیف) اینجا ثبت شود.

ابزار: `tools/vr_eval/run_eval.py` (دستی، خارج از CI). روال:
1. `python -m tools.vr_eval.run_eval build --golden golden.json --out eval.xlsx`
2. آپلود در پروژه‌ی آزمایشی، ساخت گزارش و اجرا با مدل واقعی (دو بار برای تکرارپذیری)، **بدون پاسخ دادن به سؤال‌ها**.
3. `python -m tools.vr_eval.run_eval score --golden golden.json --report ID1 --report ID2`

معیارها: دقت دسته‌بندی، درصد ردیف‌های منتهی به سؤال/باز، **خطای بی‌صدا** (غلط + شمرده‌شده + تأییدنشده)، تکرارپذیری بین دو اجرا، توکن. golden واقعی (متن شرکت) در git نمی‌رود؛ فقط `tools/vr_eval/golden.example.json` شکل را نشان می‌دهد.
