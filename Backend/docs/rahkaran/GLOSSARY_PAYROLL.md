# واژه‌نامه‌ی عوامل حقوق و دستمزد (HCM3.CompensationFactor)

تولید خودکار + قواعد استخراج‌شده از فرمول‌ها. هر «عامل» یک مقدار قابل‌محاسبه برای کارمند در هر ماه است (جدول `HCM3.PayCalcItem` برای حقوق ماهانه و `HCM3.PeriodicCalcItem` برای عیدی/سنوات). ستون‌ها: شناسه، نام لاتین، عنوان فارسی، واحد، «غیرصفر» = تعداد ردیف‌های با مقدار ≠ 0 در PayCalcItem، آخرین ماه ثبت، تعداد ردیف غیرصفر در محاسبات دوره‌ای، و مجموع ماه 140504 (میلیون ریال).

## فرمول‌های کلیدی (بر اساس توضیحات فرمول‌ها در دیتابیس)

| رابطه | توضیح |
|---|---|
| خالص پرداختی (63) | = جمع مزایا (61) − جمع کسور (62) |
| قابل پرداخت (55) | = جمع مزایای قبل از بدهی (53) − جمع کسور قبل از روند (57) |
| جمع مزایا (61) | = مجموع عوامل «مزایا» − مزایای مالیات‌پذیر غیرنقدی (مستمر و غیرمستمر) |
| جمع کسور (62) | = مجموع عوامل «کسور» |
| مأخذ بیمه (45) | = حداقل(مشمول بیمه (43) ، سقف بیمه (44)) ؛ سقف = ۷ برابر مزد روزانه × کارکرد مؤثر |
| بیمه تأمین اجتماعی سهم کارگر (46) | ۷٪ مأخذ بیمه (صفر برای جانباز/بازنشسته) |
| بیمه سهم کارفرما (64) | ۲۰٪ مأخذ بیمه (۲۷٪ برای جانباز؛ صفر برای بازنشسته) |
| بیمه بیکاری (65) | ۳٪ مأخذ بیمه (تعهد کارفرما) |
| بیمه تکمیلی سهم کارمند (72) و کارفرما (73) | هرکدام = تعداد افراد تحت تکفل × ۱۱٬۰۰۰٬۰۰۰ ریال (اگر در ماه کارکرد یا استعلاجی داشته باشد) |
| مالیات (50) | = مالیات دارایی (613) + افزاینده − کاهنده؛ مالیات حقوق ماه (49) = مالیات جاری |
| مبنای مالیات (47) | = مجموع عوامل مالیات‌پذیر مستمر نقدی − سایر معافیت‌ها (حداقل صفر) |
| مزد شغل (38) | = حقوق پایه در حکم × کارکرد مؤثر ÷ 30 |
| حق مسکن (39)، حق اولاد (40)، بن کارگری (140) | = مقدار در حکم ÷ کارکرد استاندارد ماه × کارکرد مؤثر |
| مزد سنوات (139)، فوق‌العاده شرایط کار (141)، ایاب و ذهاب (162) | = مقدار در حکم ÷ 30 × کارکرد مؤثر |
| جمع اقساط وام (52) | = جمع اقساط وام‌های ماه (از `LoanInstalment`) |
| حقوق پایه سند (277/303) | عوامل کمکی صدور سند حسابداری (پایه حقوق منهای بیمه سهم کارمند در حالت غیرعمرانی) |

> عوامل ورودی (ماموریت ورودی 164، اضافه‌کار ورودی 165، کارانه 181 و …) از جدول `MonthlyFactorData(+CompensationItem)` توسط کاربر وارد می‌شوند.

> ⚠️ عوامل با «غیرفعال» در عنوان (مثل 251 خالص پرداختی ملت، 562) منسوخ‌اند. عامل 520 «خالص پرداختی صندوق» همان خالص پرداختی است (تکرار برای فایل بانکی).
